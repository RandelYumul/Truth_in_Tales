![Truth in Tales Preview](./assets/preview.png)

---

## Overview

**Truth in Tales** is a static website dedicated to showcasing creative writing, personal essays, and reflections. The platform emphasizes readability, accessibility, and a visually organized interface, allowing visitors to focus on the content and the stories being shared.

The website consists of three main sections:

- **Home / Landing Page** – Introduces the website and its purpose.
- **Blog / Essays** – Displays creative writing pieces, personal reflections, and stories.
- **About Us** – Provides information about the website and the team behind its development.

---

## Tech Stack

- **HTML5** – Structures the website's content and pages.
- **CSS3** – Handles styling, layouts, and responsive design.
- **JavaScript** – Supports client-side interactive elements.
- **GitHub Pages** – Provides static website hosting and deployment.

---

## Features

- **Clean and Minimalist Interface** – A reader-focused layout that emphasizes simplicity and visual clarity.
- **Responsive Web Design** – Layouts designed to adapt to desktop, tablet, and mobile screens.
- **Creative Writing Collection** – Organized presentation of essays, personal reflections, and literary content.
- **Readable Typography** – Thoughtful use of typography, spacing, and contrast to improve readability.
- **Lightweight Architecture** – A static website that does not require a backend server.
- **Easy Navigation** – Organized sections that allow users to explore content conveniently.

## Getting Started

### Prerequisites

- A modern web browser such as Google Chrome, Mozilla Firefox, Microsoft Edge, or Safari.
- Git (optional, for cloning the repository).

### Running Locally

1. Clone the repository:

```bash
git clone https://github.com/RandelYumul/Truth_in_Tales.git
cd Truth_in_Tales
```

2. Open the website's HTML files in your preferred browser.

3. Navigate through the Home, Blog/Essays, and About Us sections to explore the website.
